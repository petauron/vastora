# Vastora 界面设计语言

本文是 Center 桌面、应用商店、控制面板、内置管理页及挂载应用工作区的视觉规范。后续页面沿用同一套基础组件和设计变量，不再逐页另起一套样式。

## 方向与参考

采用 macOS 式桌面与管理工具的布局：中性灰导航材质、清晰内容面板、细分隔线、紧凑控件、有层次的应用图标。参考 Apple Human Interface Guidelines 中的 App icons、Materials 和 Designing for macOS。这是 Vastora 的 Web 设计语言，不是 macOS 原生控件或 Apple 图标的复制。

完整视觉参考由 frontend-app-builder / 内置 Image Gen 生成：

- [控制面板](design/concepts/macos-settings.png)：侧栏分类、右侧分组配置。
- [应用商店](design/concepts/macos-store.png)：图标与应用资料并列、轻分隔列表。
- [应用工作区](design/concepts/macos-workspace.png)：工具栏、紧凑数据表、属性面板。
- [属性窗口](design/concepts/macos-dialogs.png)：内容自适应居中面板、分组资料、右侧主操作。

实现约束优先于生成图中的误差：保留 Vastora 标志、现有壁纸、真实应用与导航，不加入图中的 Apple 标志、Finder、邮件、日历、照片、废纸篓等无关功能。数据和文字来自真实 API/现有页面，图中样例数量、日期、分数不进入代码。应用工作区的现有列、权限、动作、错误提示全部保留；不根据示意图增删业务能力。

主要按钮使用 `--primary-control` 与白字，对比度约 4.95:1；深色文字强调使用较亮的 `--primary`，避免把适合按钮底色的深蓝用于深色背景上的小字。蓝色只用于主要操作、链接、开关和键盘焦点，不把桌面框选区域染蓝。状态色继续区分成功、警告和故障，必须伴随文字或符号。浮层采用全局语义变量，不能依赖位于桌面容器之下才能获得主题。

- 字体：系统字体栈，macOS 上使用 SF / PingFang；不下载或分发 Apple 字体。
- 页面标题 22px / 600；面板标题 15px / 600；正文与控件 13px；次级信息 12px；表格数据使用等宽数字。
- 4px 间距基准，内容区域 24–28px 内边距，分类侧栏宽 208px，密集表格行高至少 40px。控制面板默认窗口最大 1080×720px，受视口约束；展开仍可使用整个工作区。
- 控件圆角 6px，分组面板 10px，应用窗口 18px，属性窗口/对话框 14px。避免每层都包裹大圆角卡片。
- 控件短过渡 120–180ms；尊重减少动态效果。玻璃效果仅用于系统导航、侧栏和 Dock，内容不透壁纸。

## 图标

应用图标与操作图标分层：

- 应用图标使用 `AppIcon` 的 64×64 SVG，统一圆角轮廓、顶部光源、实心主体、柔和投影；每个应用使用独立的语义造型。
- 桌面 56px、Dock 50px、商店 48px、侧栏 28px、菜单/标题 20–24px。SVG 必须在这些尺寸下清晰，渐变 ID 逐实例唯一。
- 应用商店＝购物袋；主机＝银色服务器；设置＝金属齿轮；Meridian＝指南针；Pulse＝深色监视器和绿色波形；Telegram Bot＝实心纸飞机；CPA＝网关连接；Keeper＝柱形统计；Headscale＝网络节点；FileBrowser＝文件夹。
- 不用 emoji 或统一的细白线符号冒充应用图标。按钮、表格、提示中的操作符号继续使用 Lucide，默认 16px，以免色彩图标抢占数据阅读。
- 图标不表示运行状态。运行/故障/更新状态单独从真实数据呈现。
- 桌面名称透明背景、白字和轻文字阴影；外部入口标记附着图标，不单独换行。名称与可访问名称仍完整保留。

## 页面模型

### 登录与首次管理员设置

以 [登录概念图](design/concepts/macos-login.png) 为参考，使用与桌面相同的海岸壁纸、Vastora 四菱形标志及系统字体。整页居中账户区域，不使用旧的矩形登录卡片、Dock 或窗口红绿灯。

- 顶部左侧为品牌，右侧为主题和语言两个独立的圆形控件；账户头像采用代码原生的圆形磨砂材质与实心人物符号。
- 大屏表单最大宽 450px；头像 166px，标题 40px，字段标签 18px，输入与主按钮 60px 高。小于 600px 宽或 760px 高时，表单最大宽 360px、头像 96px、标题 28px、输入与主按钮 50px 高，输入文字 16px。
- 控件为中性灰磨砂材质和细白边，主操作沿用 `#006be6`。浅色保留自然海岸光线，深色降低壁纸亮度，文字始终为高对比浅色。支持键盘焦点、自动填充、减少透明度和强制颜色模式。
- 文案固定为原有“登录 Center / 使用管理员账号继续。/ 账号 / 密码 / 登录”，首次初始化使用“创建管理员 / 创建账号后即可继续设置。/ 创建并继续”及现有密码要求。显示/隐藏密码只改变显示状态，不自动提交、不保存密码。
- 连接中、连接失败与重试复用同一背景和身份区域。错误说明在对应字段下方呈现，切换语言时即时翻译并保留输入；安全验证仅在服务端要求时显示，现有验证、限速、API、跳转和权限规则不变。
- 生成图中的 `admin` 为演示输入，真实页面不预填账户；使用仓库已有壁纸，避免生成图对照片的重绘成为新的生产资产。中文与英文共享布局，小屏及安全验证扩展状态允许垂直滚动。

### 桌面

菜单栏仅提供有明确用途的入口，不能为了仿 macOS 放置没有对应功能的 Wi-Fi、电池等系统控件。浏览器与 Center 的连接由请求状态判断，不使用 Wi-Fi 图标表示；正常连接不占用菜单栏，断连时在内容区显示连接中断、上次同步时间及“立即重试”。

### 窗口交互与统一工具栏

以 Apple WWDC26「Modernize your AppKit app」的 macOS 27 更新 的统一工具栏、清晰内容边缘为参考：窗口顶部使用连续的中性灰材质、左侧红黄绿控件、紧随其后的左对齐标题和右侧操作组，移除居中的小应用图标。56px 工具栏、18px 外圆角和 17px 内圆角是本项目的 Web 实现参数，不声称像素复刻原生系统。

桌面窗口支持标题栏拖动、四边与四角缩放、绿色按钮及标题栏双击最大化/还原。最大化填满菜单栏与 Dock 之间的工作区，不触发浏览器全屏；还原返回原位置与尺寸，最大化状态拖动可带着窗口还原。窗口几何按应用独立保存在当前会话，切换/最小化不重置。缩小浏览器只投影至可见区域，不覆盖原始尺寸。最小尺寸 640×360px（可用区域更小时随之缩小），标题栏和边框不能拖出可用工作区。

标题栏按钮不触发拖动，移动超过 4px 开始；使用原生 Pointer Capture，Esc、失焦、pointercancel、视口变化取消未完成操作。标题栏获得焦点后 Alt＋方向键移动，Alt＋Shift＋方向键缩放。767px 及以下采用铺满内容布局，隐藏自由缩放和最大化控件，保留关闭/最小化与 44px 点击区域。复用现有 Pointer Events；Base UI 没有应用窗口拖动/八向缩放能力，不新增拖拽依赖。

Dock 中已打开的应用按首次打开顺序排列，新应用追加在末尾；再次激活或浏览器前进/后退只更新当前高亮，不重排图标。关闭工作区时移除对应项，不按最近使用裁掉仍打开的应用。

保留已确认交互：单击选中，双击/Enter 打开；触屏点按打开。空白处拖动灰色框选，Shift/Command/Ctrl 多选，Esc 清空。键盘焦点与选择状态相互独立。后台探针只在应用商店管理。

桌面采用响应式自由摆放网格，整个可用桌面都是落点，不限制在右侧两列；默认排列从右侧开始，用户可将图标放到任意空白格并保留空位。图标格为 98×118px、水平步距 112px、垂直步距 138px；菜单栏、Dock、安全边距和状态卡片不参与图标放置。拖动中图标跟手，空落点显示灰色虚线占位；落点已占用时寻找通往最近空格的相邻路径，路径上的图标各让出一格；距离相同优先向右、再向下、再向左或向上，右边界不能跨行跳到屏幕最左侧，也不能从底部绕回顶部，以 180ms 动画实时预览，松手结果必须与预览一致，不交换两个图标。多选图标保留相对行列形状，越界或碰到卡片则不接受放置；Esc、移出可用区域松手、失焦、滚动或视口变化取消拖动。

布局按稳定应用标识保存右侧起算的列、行，顺序另外供手机紧凑网格和辅助导航使用。窗口缩小时仅将超界/冲突位置投影到最近可见空格，不自动覆盖保存的大屏坐标；恢复宽度后恢复原布局。新增应用占用可用格，删除应用不留失效条目；图标超过可见格数时扩展可滚动区域，不能隐藏图标。767px 及以下改为文档流紧凑网格，状态卡片在上，手机点按打开并保留桌面布局。Alt＋方向键移动到相邻格，空白处仍用于框选，拖动结束不触发打开。复用 Pointer Capture，移动超过 5px 才开始拖动，固定网格坐标用于命中判定，避免被动画中的图标反复干扰。开启减少动态效果时关闭让位动画。布局空间使用 ResizeObserver 测量，不持久化屏幕像素坐标。

框选采用中性灰填充和明暗双层边线：矩形内侧为浅色实线轮廓，外侧为 1px 深色轮廓。两层分别提供暗海面和亮天空上的边界辨识度，不能再使用单条深灰细线配低透明白线。灰色填充使用上表的深浅模式变量，保留壁纸和图标细节；圆角为 2px，填充限制在内边以内。拖动期间不添加模糊滤镜、位移动画或宽高过渡，边框立即跟随指针。

增强对比度或减少透明度时使用透明内部、2px 白色内边和 1px 深色外边；强制颜色模式使用 2px 系统 `Highlight` 轮廓，取消填充和阴影。这些覆盖必须位于框选基础规则之后，避免被后续样式覆盖。框选样式不改变选区几何、命中判定、多选快捷键或触屏行为。以上数值是 Vastora 针对现有壁纸的设计参数，不声称是 macOS 27 的官方取色。

### 页面加载

页面模块或首次数据尚未就绪时，保留当前桌面/窗口外壳。桌面使用中央自适应宽度的中性磨砂提示，18px 转圈、13px 状态文字、16px 圆角，不出现通栏白卡片；预留与桌面相同的高度及 Dock 空间。应用窗口内部只用转圈与文字，继承窗口底色，不再嵌套卡片。加载完成即由实际内容替换，不虚构百分比或额外延迟；辅助技术只播报一个状态，支持减少动态效果、减少透明度与强制颜色。

初始化阶段同样使用壁纸与轻量等待提示，不借用登录表单外观。只有当前请求确认会话未授权时才展示登录，明确失败才展示连接错误；被取消或过期的初始化结果不能改变页面状态。数据尚未到达不等于连接失败，不用固定延迟掩盖请求竞态。

### 控制面板

左侧六类：通用、软件更新、数据与诊断、AI 助手、域名与访问、应用目录。右侧仅显示所选分类，使用白色分组行而非整页纵向卡片。支持现有 `#assistant`、`#catalog` 直达入口和浏览器前进/后退；切换分类不丢弃已填写的配置。保存、验证、刷新、诊断和危险操作沿用原来的 API 与确认流程。

### 应用商店

名称固定为“应用商店”。分类为已安装、所有应用、可用更新；搜索与分类协同。以用户提供的群晖应用网格为密度参考，保留 Vastora 的 macOS 窗口与图标语言：

- 桌面应用格最小宽度 230px、高度 132px，48px 图标在左，右侧为最多两行名称、一行状态/说明及一个 26px 胶囊主按钮。网格用单像素分隔，末行空位保持页面底色。
- 在 1536px 视口、默认窗口下，实测每行 4 格、每格约 268×132px。列数随可用宽度变化，不固定为截图中的 8 列。
- 手机改为 88px 起的单行布局，图标、名称/状态、主按钮横向排列；主按钮至少 44px 高。长名称允许换行，内容可撑高，不裁掉操作。
- 已安装应用显示运行、处理中、需处理或可更新摘要；前台主按钮为“打开”，后台为“管理”，更新分类为“查看更新”。
- 点击名称查看完整说明、目录来源、目录版本、配方修订、权限及安装状态，详情提供管理入口；安装限制仍在网格中提示，长文可在详情完整阅读。第三方来源保留在网格摘要，避免同名混淆。
- 不为了统一格式虚构安装日期，也不把详细版本、所有主机和多个管理按钮挤回网格。

### 工作区与其他管理页

主机、网络、活动、概览、助手和应用工作区共享标题、工具栏、表格、表单、按钮、标签、分段控件、弹出菜单、对话框与属性面板的样式。数据页面优先列表/表格；不把表格改成卡片墙。表格列名和操作语义不变。官方 Meridian 通过现有可信挂载接口继承语义变量及 `data-slot` 组件样式，继续由 Meridian 仓库拥有其产品页面。

普通应用管理页使用“应用图标与标题 + 已安装节点列表”的结构，去除标题、搜索、数据嵌在巨大卡片内的旧布局。节点、运行状态、入口及操作在桌面同一行呈现，默认行高 64px，长内容可撑高；“打开”和“管理”显示文字。仅多节点时提供搜索；单节点不重复显示数量或放空搜索框。窄于 760px 的工作区改为带字段标签的两列行布局，节点名称与操作各占整行；样式按组件和容器宽度定义，避免应用挂载的全局工具类打乱布局。

### 浮层与表单

设置编辑继续复用 Base UI Sheet 的焦点与关闭语义。左右侧编辑面板统一为内容自适应的居中属性窗口，默认最大宽 560px，复杂管理页可显式选择更宽尺寸。顶/底部启动器保持原来的展开模型。

- 短表单按内容确定高度，不留整屏空白；桌面最大高 `min(820px, 100svh - 96px)`。手机四周至少留 16px，最大高 `100svh - 32px`，不贴满视口。
- 表单主体可独立滚动，标题和底部操作不收缩。嵌套表单必须设置 `min-height: 0`，避免内容撑出窗口；手机输入与主要操作目标至少 44px 高。
- 窗口圆角 14px，遮罩黑色 16%，不模糊工作区。浮层使用全局语义颜色，深色模式不能继承浅色硬编码。
- 主操作位于次操作之后，视觉顺序和键盘 Tab 顺序一致；不能只用 CSS `order` 反转按钮。
- 确认使用现有 Dialog/AlertDialog，保持焦点管理、标题、错误提示及危险操作确认。统一 `useConfirmation` 替代浏览器原生 confirm；取消、关闭和卸载视图均按不确认处理，关联节点中断提示不可省略。
- 折叠详情统一细小箭头，正文页与 portal 弹窗同样生效，隐藏浏览器默认 marker。
- 公共 Button、Input、Switch、Tabs、Table 沿用现有 Base UI/shadcn 语义。链接保持链接语义，只复用样式，不能伪装成无法正常新标签打开的按钮。

节点网络使用紧凑分隔行，列出名称与在线状态、网络能力、服务地址和操作；窄窗口自动换行，不重复堆叠整张卡片。所有网络决策、警告、业务字段和确认条件保留。

## 响应式与可访问性

- 760px 以下侧栏改为可横向滚动的分类入口，内容全宽，不能挤压表单。商店目录设置保留为同行 44px 图标按钮与完整可访问名称。
- 小屏标题 20px；输入文字至少 16px，防止移动 Safari 自动缩放。
- 触屏操作目标至少 44px；密集表格可横向滚动，保留原有移动端行布局。
- 深浅色均使用语义变量；减少透明度时使用不透明中性表面；强制颜色模式保留边框与焦点。
- 所有可交互图标有可访问名称，装饰图标隐藏；保留键盘导航、表单 label、真实状态文字。

## 实现位置与维护

- `web/src/index.css`：主题变量与桌面壳层。
- `web/src/styles/macos.css`：共享控件、页面、设置与浮层规则。
- `web/src/components/desktop/AppIcon.tsx`：应用图标唯一入口。
- `web/src/components/ui/*`：成熟基础控件，业务层只选择变体和布局。
