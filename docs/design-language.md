# Vastora 界面设计语言

本文是 Center 桌面、应用商店、控制面板、内置管理页及挂载应用工作区的视觉规范。后续页面沿用同一套基础组件和设计变量，不再逐页另起一套样式。

## 方向与参考

采用 macOS 式桌面与管理工具的布局：中性灰导航材质、清晰内容面板、细分隔线、紧凑控件、有层次的应用图标。参考 Apple Human Interface Guidelines 中的 App icons、Materials 和 Designing for macOS。这是 Vastora 的 Web 设计语言，不是 macOS 原生控件或 Apple 图标的复制。

完整视觉参考由 frontend-app-builder / 内置 Image Gen 生成：

- [控制面板](design/concepts/macos-settings.png)：侧栏分类、右侧分组配置。
- [应用商店](design/concepts/macos-store.png)：图标与应用资料并列、轻分隔列表。
- [应用工作区](design/concepts/macos-workspace.png)：工具栏、紧凑数据表、属性面板。

实现约束优先于生成图中的误差：保留 Vastora 标志、现有壁纸、真实应用与导航，不加入图中的 Apple 标志、Finder、邮件、日历、照片、废纸篓等无关功能。数据和文字来自真实 API/现有页面，图中样例数量、日期、分数不进入代码。应用工作区的现有列、权限、动作、错误提示全部保留；不根据示意图增删业务能力。

## 视觉变量

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| 工作区背景 | `#f5f5f7` | `#202022` |
| 内容/分组面板 | `#ffffff` | `#2b2b2e` |
| 主文字 | `#1d1d1f` | `#f5f5f7` |
| 次文字 | `#6e6e73` | `#aaaab0` |
| 分隔线 | `#dedee3` | `#424246` |
| 主要按钮底色 | `#006be6` | `#006be6` |
| 链接 / 强调色 | `#006be6` | `#409cff` |
| 侧栏选中 | 中性灰 `#dedee3` | 中性灰 `#454549` |
| 框选区域 | 中性灰填充 + 灰色边线 | 同一中性灰逻辑 |

主要按钮使用 `--primary-control` 与白字，对比度约 4.95:1；深色文字强调使用较亮的 `--primary`，避免把适合按钮底色的深蓝用于深色背景上的小字。蓝色只用于主要操作、链接、开关和键盘焦点，不把桌面框选区域染蓝。状态色继续区分成功、警告和故障，必须伴随文字或符号。浮层采用全局语义变量，不能依赖位于桌面容器之下才能获得主题。

- 字体：系统字体栈，macOS 上使用 SF / PingFang；不下载或分发 Apple 字体。
- 页面标题 22px / 600；面板标题 15px / 600；正文与控件 13px；次级信息 12px；表格数据使用等宽数字。
- 4px 间距基准，内容区域 24–28px 内边距，分类侧栏宽 208px，密集表格行高至少 40px。控制面板默认窗口最大 1080×720px，受视口约束；展开仍可使用整个工作区。
- 控件圆角 6px，分组面板 10px，窗口/对话框 12–14px。避免每层都包裹大圆角卡片。
- 控件短过渡 120–180ms；尊重减少动态效果。玻璃效果仅用于系统导航、侧栏和 Dock，内容不透壁纸。

## 图标

应用图标与操作图标分层：

- 应用图标使用 `AppIcon` 的 64×64 SVG，统一圆角轮廓、顶部光源、实心主体、柔和投影；每个应用使用独立的语义造型。
- 桌面 56px、Dock 50px、商店 48px、侧栏 28px、菜单/标题 20–24px。SVG 必须在这些尺寸下清晰，渐变 ID 逐实例唯一。
- 应用商店＝购物袋；主机＝银色服务器；设置＝金属齿轮；Meridian＝指南针；Pulse＝深色监视器和绿色波形；Telegram Bot＝实心纸飞机；CPA＝网关连接；Keeper＝柱形统计；Headscale＝网络节点；FileBrowser＝文件夹。
- 不用 emoji 或统一的细白线符号冒充应用图标。按钮、表格、提示中的操作符号继续使用 Lucide，默认 16px，以免色彩图标抢占数据阅读。
- 图标不表示运行状态。运行/故障/更新状态单独从真实数据呈现。
- 桌面名称透明背景、白字和轻文字阴影；外部入口标记附着图标，不单独换行。名称与可访问名称仍完整保留。

## 页面模型

### 桌面

保留已确认交互：单击选中，双击/Enter 打开；触屏点按打开。空白处拖动灰色框选，Shift/Command/Ctrl 多选，Esc 清空。键盘焦点与选择状态相互独立。后台探针只在应用商店管理。

### 控制面板

左侧六类：通用、软件更新、数据与诊断、AI 助手、域名与访问、应用目录。右侧仅显示所选分类，使用白色分组行而非整页纵向卡片。支持现有 `#assistant`、`#catalog` 直达入口和浏览器前进/后退；切换分类不丢弃已填写的配置。保存、验证、刷新、诊断和危险操作沿用原来的 API 与确认流程。

### 应用商店

名称固定为“应用商店”。分类为已安装、所有应用、可用更新；搜索与分类协同。以用户提供的群晖应用网格为密度参考，保留 Vastora 的 macOS 窗口与图标语言：

- 桌面应用格最小宽度 230px、高度 132px，48px 图标在左，右侧为最多两行名称、一行状态/说明及一个 26px 胶囊主按钮。网格用单像素分隔，末行空位保持页面底色。
- 在 1536px 视口、默认窗口下，实测每行 4 格、每格约 268×132px。列数随可用宽度变化，不固定为截图中的 8 列。
- 手机改为 88px 起的单行布局，图标、名称/状态、主按钮横向排列；主按钮至少 44px 高。长名称允许换行，内容可撑高，不裁掉操作。
- 已安装应用显示运行、处理中、需处理或可更新摘要；前台主按钮为“打开”，后台为“管理”，更新分类为“查看更新”。
- 点击名称查看完整说明、目录来源、目录版本、配方修订、权限及安装状态，详情提供管理入口；安装限制仍在网格中提示，长文可在详情完整阅读。第三方来源保留在网格摘要，避免同名混淆。
- 不为了统一格式虚构安装日期，也不把详细版本、所有主机和多个管理按钮挤回网格。

### 工作区与其他管理页

主机、网络、活动、概览、助手和应用工作区共享标题、工具栏、表格、表单、按钮、标签、分段控件、弹出菜单、对话框与属性面板的样式。数据页面优先列表/表格；不把表格改成卡片墙。表格列名和操作语义不变。官方 Meridian 通过现有可信挂载接口继承语义变量及 `data-slot` 组件样式，继续由 Meridian 仓库拥有其产品页面。

### 浮层与表单

设置编辑使用现有 Sheet，桌面上为带圆角和边距的属性面板，小屏为全宽面板。确认使用现有 Dialog/AlertDialog，保持焦点管理、Esc、标题、错误提示及危险操作确认。公共 Button、Input、Switch、Tabs、Table 等均沿用现有 Base UI/shadcn 语义，不自行重写交互。

## 响应式与可访问性

- 760px 以下侧栏改为可横向滚动的分类入口，内容全宽，不能挤压表单。商店目录设置保留为同行 44px 图标按钮与完整可访问名称。
- 小屏标题 20px；输入文字至少 16px，防止移动 Safari 自动缩放。
- 触屏操作目标至少 44px；密集表格可横向滚动，保留原有移动端行布局。
- 深浅色均使用语义变量；减少透明度时使用不透明中性表面；强制颜色模式保留边框与焦点。
- 所有可交互图标有可访问名称，装饰图标隐藏；保留键盘导航、表单 label、真实状态文字。

## 实现位置与维护

- `web/src/index.css`：主题变量与桌面壳层。
- `web/src/styles/macos.css`：共享控件、页面、设置与浮层规则。
- `web/src/components/desktop/AppIcon.tsx`：应用图标唯一入口。
- `web/src/components/ui/*`：成熟基础控件，业务层只选择变体和布局。
- `web/src/views/SettingsView.tsx`：设置分类与分组。
- `web/src/views/shared.tsx`：公共页面标题。

新页面不得另设硬编码深浅色控件样式。本轮用户确认范围为 Vastora 内全部页面。独立打开的 Pulse、Telegram Bot 等网页不在此次重设计范围；它们有自己的前端和发布流程。
