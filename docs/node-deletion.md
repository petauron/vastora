# 删除已停用节点

节点页在已停用节点上显示「删除节点」。输入节点名称后确认，成功后从列表移除。

- 停用：`POST /api/v1/agents/{id}/disable`，撤销管理访问，保留记录。
- 删除：`DELETE /api/v1/agents/{id}`，只允许已停用且不再被使用的节点。
- 两个操作均要求管理员登录和现有写操作保护。
- 删除不会连接服务器、卸载 Agent 或删除服务器文件。
- 仍运行的应用、访问入口、网关、落地服务及未完成的更新/卸载操作会阻止删除。
- 已卸载应用及已完全停止入口的 Center 历史记录随节点清理。
- 清理和节点删除在同一个事务中执行；其他依赖由外键继续保护，失败时整体回滚。
- 不修改数据库结构，不提供旧 DELETE 停用语义的兼容路径。

新增后端用例覆盖停用前置条件、凭据失效、落地机保护、应用占用、历史记录清理及失败回滚；前端用例覆盖名称确认。按仓库规则，开发时未运行本地测试、构建或浏览器 QA。
