# 客户端落地订阅（#409，MVP）

入口：应用 → 3x-ui → 节点列表 → 出口组合。

## 首版范围

- 保留原订阅地址；每个节点勾选本机出口和多个落地，按勾选项生成普通订阅节点。取消本机出口会移除订阅中的原 VLESS 节点。
- 一个入口可一次选择多个落地机，每个组合生成使用独立身份的普通 VLESS 节点；不再提供客户端自选策略。
- 仅同步给已获准使用该入口的客户端；后续新增客户端继承节点出口设置，不扩展入口权限。客户端不再单独配置组合。
- 父账号与组合共用原套餐的流量、到期时间及续期设置，不复制多份免费额度。
- 有限套餐由 Agent 汇总所有身份的单调计数；未耗尽时各身份不配置会随采样变化的单独额度，达到父额度后统一停用。当前最多存在一个 15 秒采样周期加在途流量的超额窗口，不承诺字节级实时硬截断。
- 保留手动停用、删除、撤销和必要的失败重试；撤销不退还已消费流量。
- 新增落地用途支持 TCP/HTTPS，不声明 UDP、QUIC 或 FullCone 支持。启用 HY2 的入口必须保留本机出口；固定落地组合目前只生成 VLESS 节点。保存时撤除旧的整机强制出口，避免原节点也走落地。

## 订阅用法

继续使用原 `/sub/<token>` 地址提供原节点和组合节点。
完整 Mihomo 输出使用同域名的 `/clash/<token>`，或由原订阅路径识别 Mihomo 客户端。

Agent 首次导入 3x-ui 已有的客户端 UUID、订阅令牌、受管 REALITY
入口材料和计量水位，随后以本地加密状态直接生成普通 base64 与 Mihomo
订阅；订阅请求不再实时读取或合并 3x-ui 的 2096 正文。旧订阅 URL 和
令牌保持不变，3x-ui 后续变更不能静默旋转已分发的令牌。

3x-ui 在迁移阶段仍是 Xray 客户端投影与流量计数适配器，但不是订阅内容
或授权事实来源。首次导入后，Agent 每 15 秒只读刷新用量；只有 Vastora
确认的客户端变更才能更新材料、入口和套餐字段。内容无变化时不写加密
快照，也不写 Xray 或触发重载。未确认的入口、身份冲突、重复令牌、
缺少受管公开 Host 或无法生成 REALITY 材料时失败关闭，不能回退到另一份
3x-ui 订阅正文。

订阅可直接使用，也可交给支持 VLESS/REALITY 的普通订阅转换器；固定
组合不依赖 dialer-proxy、自定义策略组或转换后合并。
修改授权时只确认本次实际调整的入口，不保存供未来自动断连使用的授权快照。

## 必要约束

- 凭据和账本加密保存；同名的新账号不能继承旧账号的权限。
- 先确认路由和原生身份更新，再发布组合；原生写入返回 `nodePending` 时，只查询原入口的同步状态，单次写入最多等待 45 秒，不重复提交。读取异常、取消、超时或写入结果不确定时停止，保留人工恢复边界。
- 套餐按实际到期时间下发，不使用 90 秒短期续约。到期和额度由父账户统一控制；按周期续期只推进一次用量基线，普通采样不重新分配子身份额度或重载 Xray。
- 手动停用、删除和撤销仍完成必要的路由与身份处理，不影响未操作的授权。
- 保留既有入口到落地的直连检查和故障阻断，不新增 Center 失联时的跨节点账号断连系统。
- 首版不提供共享账本跨订阅主机迁移。仅保留拒绝不安全迁移的检查，避免把部分额度当作新套餐；不将开发迁移系统列为首版待办。
- 数据库仍使用备份优先的前向迁移，不因精简产品范围而删除数据库安全迁移。

## Vastora 原生接入迁移（#505）

Center 管理授权和修订，Agent 保存加密的客户端材料并生成订阅；3x-ui
不能反向覆盖这些业务事实。单一过渡控制节点仍使用 3x-ui 客户端 API
作为单向投影与汇总计量适配器，但所有 worker 已切换为 Agent 托管的
Xray-only 运行时，不再运行 3x-ui 面板、数据库、更新器或订阅服务。

#394 的 worker 切换沿用同一账户、凭据和修订模型。旧控制节点降级时先
保存恢复点，再进入独立的 `convert_worker` 阶段；Xray 候选验证并替换成功
后才允许拓扑接入。失败会保留恢复材料和明确重试边界，不提供双写或旧
worker 运行时 fallback。最终移除唯一过渡控制适配器属于后续控制面切片；
本次不改变非 VLESS 计算节点。

## 固定组合精简

移除自选策略和“同时提供”的配置入口、API 和数据面私网例外。一个入口多选落地后，在一个事务内登记全部组合；已有单写者按序应用，完成的组合才进入订阅。本机出口是否发布由节点多选项决定；取消落地选项同步撤销对应组合，不共用认证身份。

数据库 76 使用现有迁移前备份机制；若仍有未撤销的旧自选/混合授权，迁移停止，要求先在原版本撤销后升级，不静默扩权或删除凭据。没有旧授权的安装正常前向升级。旧账号发布模式归一为固定组合。

本次未运行测试、构建或浏览器 QA，也未修改线上配置。

## 订阅入口修复（2026-09-14）

组合订阅由 Agent 的私网 2097 端口提供，不能仍将公网域名指向 3x-ui 原生 2096 端口。Token 模式的 cloudflared 使用云端入口配置：Tunnel 任务消费一次性执行许可后，Center 同步并回读该配置，再允许 Connector 执行；不能把容器启动成功等同于入口配置成功。已有规则的 originRequest 和全局设置保留。

受管 Docker 网桥访问宿主 Agent 会经过 INPUT 链。Agent 仅允许该网桥源网段访问自身私网地址的 TCP 2097，不开放公网；服务退出或换址时删除精确匹配的受管规则，规则写入异常时停止。

现场先备份并修复云端回源和主机 INPUT 规则，随后同一公网订阅的原始链接和 Clash/Mihomo 两种格式均返回 11 个节点，包含 4 个已就绪组合。该证据仅确认订阅发布链路，不替代代理业务流量验证，也不表示其余未完成授权已恢复。本次本地回归用例未执行，发布使用现有 alpha 最小 CI。
