# Vastora 图标规范 · Color Planes

## 视觉原则

液态玻璃只用于窗口、Dock 等界面容器。图标采用独立轮廓、不透明色块、克制的相近色渐变。渐变表达配色变化，不模拟光源和材质。

用户已否定 Satin Relief 的统一银白底板及浮雕处理，本规范取代该方向；旧效果图和评分仅为历史记录。

- 按场景使用底板：桌面、Dock、启动器、应用商店等应用身份使用统一圆角底板；控制面板内部功能入口保持独立轮廓。底板按主体配色选择浅蓝、浅橙、灰蓝、浅青、浅绿或浅紫，不全部使用白色。
- 底板由 AppIcon 的 CSS 统一提供，不重绘进源图；轮廓统一使用 `app-tile-mask.svg` 的平滑圆角蒙版，直边逐渐进入弧线，不使用普通百分比圆角，图形约占底板74%，无高光、边框或浮雕阴影。浏览器、目录本身的面板属于功能图形。
- 不用高光、倒角、浮雕、投影、金属纹理、塑料光泽或玻璃透色。
- 层次来自形状叠放、色块对比和留白。保持正视图，主次清楚。
- 每个图标一个主要寓意，最多一个辅助形状；不增加星光、徽章和装饰。
- 配色鲜明但克制，主体在浅色、深色背景都应完整可辨。
- 工具栏的搜索、关闭和返回继续使用矢量功能符号。

## 生成约束

每个资产单独使用 Image Gen 绘制。主体完整、色块不透明；不得把图标内部的白色符号当成背景删除。

```text
Freestanding desktop utility icon, precise front-facing geometry.
Opaque color planes and restrained analogous hue gradients.
Gradients are color transitions, not lighting.
No enclosing tile, bevel, embossing, highlight, light source,
shadow, reflection, gloss, texture or 3D material.
Balanced negative space, clear at small sizes.
```

## 导出与验收

运行时资产位于 web/public/icons/flat-color/，256×256 WebP，主体最大边约210px。目录名不代表旧规范继续有效。
机械处理仅限外围透明、留白、尺寸和编码，不重绘 RGB。先识别与画布边缘连通的背景，再保留封闭主体中的白色。真实箭头镂空应保留。

此规范统一用于全部24枚产品身份图标，覆盖桌面、Dock、启动器、窗口标题、应用商店、应用管理和控制面板。主页58px、详情导航23px。检查主体无误透明、底板符合使用场景，浅深背景下边缘干净；禁止用旧图或旧评分宣称新版本通过。

| senulun | Senulun | 深绿监控面板、绿色波形 |

所有应用入口沿用彩色九宫格形状，采用与应用图标一致的平滑圆角蒙版与灰蓝底板，无边框和阴影。它是既有 CSS 几何图形；其余24枚为 Image Gen 资产。搜索、关闭、返回、展开等操作图标不替换为彩色大图标。

## 复用与范围

各页面统一通过 AppIcon / VisualIcon 引用同一资源，不能为 Dock 或商店保留不同风格副本。应用显示名必须读取应用目录的本地化 name，不得在前端覆盖为功能名称。Glivela 的内部应用 key 仍使用 meridian 标识。外部独立应用页面不属于 Vastora 界面改造范围。

## 验收记录

检查浅深背景、24/40/64px图标和桌面、应用商店、主机管理、控制面板实际页面。验收关注：应用身份有统一彩色底板、设置功能无额外底板、无光照高光、主体无误透明、大小一致、文字和入口行为不变。历史 Satin Relief 图和评审仅为废弃记录，不得作为当前规范。

### 发布接入范围

运行时采用共享 AppIcon / VisualIcon，覆盖桌面、Dock、启动器、窗口标题、应用商店和应用管理。控制面板已有功能导航使用 glyph 变体，不带应用底板。图标 CSS 独立存放在 web/src/styles/icons.css。

用户与群组、主机备份等尚未发布的功能不随图标发布开放；九个入口的图形规范可供后续接入。当前发布保留主线多窗口、拖动和响应式交互。历史本地预览记录不代表本次发布验证；本次检查结果以对应提交的 CI 为准。
