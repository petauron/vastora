## 视觉参考中的刻意修正

1. 不采用生成图误加的 Apple 标志，保留 Vastora 标志。
2. 不采用生成图里的无关 Dock 应用；只列真实系统入口与已打开应用。
3. 保留现有壁纸与窗口行为；不从概念图提取背景替换壁纸。
4. 正文、版本、状态、订阅、质量分数来自现有业务模型，不使用概念图样例数据。
5. Meridian 仍由应用提供页面，不在 Center 复制一套产品界面，也不加入生成图多出的用户权限等导航。
6. 保留现有功能安全提示、权限、安装限制、目录来源和版本信息。
7. 主要按钮采用 `#006be6` 白字（约 4.95:1），比生成稿略深；深色文字强调使用 `#409cff`。焦点采用各主题的 ring 变量。
8. 独立应用网页不在本轮范围，用户已确认。

## 概念与实现对照

在概念图原始尺寸 1536×1024 对照，并单独核对 390×844 手机视口。设计图与实际截图均通过 `view_image` 查看。

| 对照项 | 概念参考 / 渲染发现 | 处理 |
| --- | --- | --- |
| 布局与密度 | 设置侧栏和分组符合参考；初版窗口过大、留白多 | 默认控制面板收紧至最大 1080×720px，保留展开功能 |
| 商店表面 | 参考为中性侧栏；初版透出过多壁纸色 | 统一灰色侧栏材质，减少透明度时使用不透明灰色 |
| 图标 | 参考为实心、分层的独立图形 | 各应用采用独立 SVG 造型，统一轮廓、光源、阴影和尺寸 |
| 字体与控件 | 参考为紧凑系统字体、轻边线 | 保留 22/15/13/12px 层级；表单、表格、浮层继承共同变量 |
| 配色 | 中性灰选择、白色内容、蓝色主操作 | 灰色框选与透明标题已核对；修正深色按钮白字对比度 |
| 手机布局 | 桌面参考未覆盖手机；初版目录设置多占一行 | 分类可横向滚动，目录设置压为同行图标按钮；无整页横向溢出 |
| 共享主题 | Meridian 独立资源在开发模式中可能后于 Center CSS | 插入点同时识别 style/link，实际挂载确认顺序与生产一致 |
| 可见文字 | 参考示例中含 Apple、无关 Dock 图标及不同业务数据 | 使用真实产品名称、分类、字段与动作；已逐项核对，无新增示例业务或功能 |

这些设计方向已按规范落实；不声称与生成概念中的每个像素或示例内容一致。现有业务导航、权限、版本、状态和动作优先保留。
